# sistema-desconto-progressivo
Sistema de Desconto Progressivo

Programa desenvolvido em Python para calcular descontos de acordo com o valor total de uma compra.
Regras de desconto
Compras abaixo de R$ 200,00: 5% de desconto.
Compras de R$ 200,00 até R$ 299,99: 10% de desconto.
Compras a partir de R$ 300,00: 15% de desconto.
Funcionamento:
O programa solicita o valor total da compra, identifica o percentual de desconto correspondente, calcula o valor do desconto e apresenta o valor final a ser pago.
Linguagem utilizada:
Python
